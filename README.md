This repository is intended strictly for educational and research purposes focused on reverse engineering, malware analysis, and understanding techniques used by stealers.

The content includes decompiled samples for studying internal behavior, persistence methods, data collection mechanisms, command & control communication, and obfuscation techniques.

This project aims to help students and researchers learn about:

Reverse Engineering
Malware Analysis
Threat Intelligence
Threat Detection & Mitigation
Offensive and Defensive Security Research

None of the material provided here should be used for malicious or illegal activities.
